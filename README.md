# 付箋タスク管理

Excelの付箋をクリックしてタイトル・内容・備考を編集し、ステータスで色と配置を変えるブックです。

## 使い始める

1. **[付箋タスク管理.xlsm](付箋タスク管理.xlsm)** をWindowsのデスクトップ版Excelで開きます。
2. このファイルのマクロを有効にします。
3. **［＋ 新しい付箋］** を押し、タイトル・内容・備考を入力します。
4. ステータスを選び、**［登録・更新］** を押します。付箋が表示され、ファイルも保存されます。

色や操作を試す場合は **[付箋タスク管理_サンプル.xlsm](付箋タスク管理_サンプル.xlsm)** を使ってください。実用用のブックにはサンプルデータが入りません。PythonやVBAの手動インポートは通常の利用には不要です。

## ステータス

| ステータス | 付箋の色 | 表示先 |
| --- | --- | --- |
| 起票済み | 黄色 | タスクボード |
| 対応中 | 青色 | タスクボード |
| 対応済み | 緑色 | タスクボード |
| 連携済み | 紫色 | タスクボード |
| 完了 | 灰色 | 完了 |

付箋をクリックすると「付箋の編集」が開きます。ステータスを変えて［登録・更新］を押すと、色と配置が自動で変わります。「完了」ではタスクボードから消え、灰色の付箋として「完了」シートに移ります。

完了した付箋も編集できます。ステータスを戻して登録するとタスクボードへ復帰します。完了時刻は完了後の追記では保持し、再開時に空欄へ戻します。再度完了した際は新しい完了時刻になります。

## 入力・表示・保存

- タイトル：必須、120文字まで。
- 内容・備考：それぞれ8000文字まで。空欄でも登録可能です。
- 文字はMeiryo UI。文字数はVBAのUTF-16単位なので、一部の絵文字は2文字分です。
- 改行は `Alt+Enter`。セルの編集は `F2` またはダブルクリックです。
- 付箋には冒頭を表示します。全文は「付箋の編集」と「タスク一覧」に保存します。長文は数式バーを広げて確認できます。
- 各ステータス列は登録順に整列します。完了シートも登録順で左から並びます。ドラッグによる移動ではステータスは変わりません。
- ［登録・更新］で自動保存します。入力途中の下書きを残して閉じる場合は `Ctrl+S` で保存してください。
- ［タスクボードへ］で戻っても入力は残ります。［入力中の付箋］で戻れます。未登録の内容を別の付箋で上書きする前には確認を表示します。
- 「タスク一覧」は全文・ステータス・作成日時・更新日時・完了日時を保持します。フィルターや `Ctrl+F` で検索でき、行のダブルクリックで編集画面が開きます。
- ［再描画］は一覧のデータから付箋を作り直します。付箋の本文を手動で図形編集する運用には対応していません。

## 利用環境

Windowsのデスクトップ版ExcelとMeiryo UIを想定しています。ブラウザー版ExcelではVBAは実行されません。Mac版での動作・フォント表示は未検証です。個人での利用を想定し、複数人の同時編集には対応していません。

保存形式は `.xlsm` を維持してください。読み取り専用で開いた場合は、編集できる場所へ名前を付けて保存します。

マクロの許可は、このファイルについて行ってください。組織の設定によって実行が制限されている場合は、その管理方針に従ってください。通常の利用に「VBAプロジェクトオブジェクトモデルへのアクセスを信頼する」の変更は不要です。[Microsoftのマクロ設定の説明](https://support.microsoft.com/en-us/excel/change-macro-security-settings-in-excel)

## ファイル構成

| ファイル | 用途 |
| --- | --- |
| `付箋タスク管理.xlsm` | 空の実用用ブック |
| `付箋タスク管理_サンプル.xlsm` | 5ステータスの動作確認用サンプル |
| `src/TaskBoard.bas` | 登録・編集・表示・保存のVBA |
| `src/TaskRules.bas` | 色・入力検証・完了日時のVBA |
| `src/ThisWorkbook.cls` | 起動時・一覧ダブルクリック時のイベントコード |
| `tools/build_workbook.py` | ブックの再生成 |
| `tools/Test-Excel.ps1` | Excel実機での確認。検証用コピーのみ操作 |
| `tests/test_workbook.py` | ファイル構造・VBAロジックの自動テスト |

ブックはコードネームでシートを参照します。シートの削除やコードネームの変更はしないでください。入力欄以外は誤操作防止のシート保護を設定しています。これはアクセス制御や暗号化ではありません。

## 開発者向けの再生成・テスト

Python 3.12で作成しました。開発用ライブラリは `requirements-dev.txt` で固定しています。

```powershell
python -m pip install -r requirements-dev.txt
python -X utf8 tools\build_workbook.py
python -X utf8 -m unittest discover -s tests -v
```

再生成先は `.build/output/` です。作業フォルダー直下の実用ブックを上書きしないため、使用開始後に再生成しても登録済みタスクを消しません。更新版へ切り替える際は、既存ブックを別途保管してください。

VBAソースはUTF-8で管理し、埋め込み時にCP932とCRLFへ変換しています。Officeが作成した空のVBAプロジェクトを基にpyOpenVBAでコードを組み込みます。独立したOLE読み取り・展開によって埋め込みコードとソースの一致を検査しています。

この実行環境ではExcelのCOM起動が `0x80080005 (CO_E_SERVER_EXEC_FAILURE)` で失敗したため、実際のExcelによるマクロのコンパイル・描画・クリック・ディスク保存は未検証です。自動テストではpyOpenVBAのVBA実行環境を使い、未対応の `Workbook.ReadOnly` と描画処理をテスト用に代替しています。Excel実機での動作確認とは区別してください。

実機での自動確認は、未使用の実用用ブックに対して次を実行します。元ブックは変更せず、`.build/native-*/native-test.xlsm` で登録・全ステータス・色・フォント・完了移動・再開・保存再読込を確認します。既存のマクロ実行ポリシーを変更する処理はありません。

```powershell
.\tools\Test-Excel.ps1 -WorkbookPath .\付箋タスク管理.xlsm
```

クリック操作の確認はサンプルブックで行います。

1. サンプルの付箋をクリックし、全文と備考が表示されることを確認する。
2. ステータスを変更して登録し、付箋の色と列が変わることを確認する。
3. 完了にして登録し、灰色の付箋が「完了」に移ることを確認する。
4. 完了から対応中に戻し、タスクボードへ復帰することを確認する。
5. 日本語と改行を入力して登録し、閉じて開き直して内容が残ることを確認する。
6. 未登録の入力がある状態で別の付箋を開き、確認で［いいえ］を選ぶと入力が保持されることを確認する。

生成にはXlsxWriter（BSD-2-Clause）・pyOpenVBA（MIT）、検証にはopenpyxl（MIT）・olefile（BSD）を使用しています。利用者が開くブックはPythonへの依存や外部通信を持ちません。
